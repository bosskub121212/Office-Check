# โปรแกรมตรวจบิล (Invoice Checker) — สเปค

วันที่: 30 ต.ค. 2569 · สถานะ: อนุมัติแล้ว (ผู้ใช้สั่งเริ่มเขียนโปรแกรม)

## เป้าหมาย
นักบัญชีอัพโหลดไฟล์บิล .xlsx ของแต่ละเดือน โปรแกรมอ่านใบกำกับภาษี / ใบวางบิล / ใบเสร็จ
แล้ว (1) ตรวจว่าเอกสารในไฟล์เดียวกันตรงกันไหม (เพราะนักบัญชีมัก copy ไฟล์เก่ามาแก้)
(2) สรุปยอดขาย ภาษีขาย สินค้าที่ขาย รายเดือน (3) แยกใบวางบิล ยอดครบกำหนด และ
แจ้งเตือนยอดที่ยังไม่ได้รับเงิน ให้นักบัญชีกด "ได้รับเงินแล้ว" ได้

## ผู้ใช้และเครื่อง
- นักบัญชีใช้คนเดียว เครื่องเดียว (Windows 10/11)
- เครื่องผู้ใช้ (ศิวสิทธิ์) เป็นเครื่อง DEV แก้บั๊กแล้วส่งเวอร์ชันใหม่ผ่าน GitHub Releases (repo public)

## โครงสร้าง
Python 3.12 + pywebview (หน้าจอ HTML/CSS แบบ A · Lavender Glass) + openpyxl + SQLite → PyInstaller onefile `InvoiceChecker.exe`

| โมดูล | หน้าที่ |
|---|---|
| `app/thaidate.py` | แปลงวันที่ พ.ศ. · คำนวณวันครบกำหนดจาก "เครดิต N วัน" / "เงินสด" |
| `app/reader.py` | อ่าน .xlsx → `ParsedFile` (IV/BI/RE + เลข B/R จากชื่อไฟล์) หาค่าจากป้าย ไม่ยึดเลขแถว |
| `app/checker.py` | กฎตรวจภายในไฟล์ → `Issue(level, code, message)` |
| `app/store.py` | SQLite ใน `%LOCALAPPDATA%\InvoiceChecker\` · เก็บไฟล์ที่อ่านแล้ว · การรับเงิน · backup อัตโนมัติ |
| `app/ledger.py` | คำนวณ "บิลที่มีผล" ข้ามไฟล์ (กฎเลขซ้ำ) · สรุปเดือน · ครบกำหนด · คาดว่าได้รับ |
| `app/export.py` | ส่งออก Excel 5 sheet |
| `app/api.py` | ฟังก์ชันที่หน้าจอเรียก (pywebview js_api และ dev server ใช้ร่วมกัน) |
| `app/updater.py` | เช็ค/โหลด/สลับเวอร์ชันจาก GitHub Releases |
| `app/bugreport.py` | zip log + ไฟล์ที่อ่านพลาด + เวอร์ชัน |
| `ui/` | หน้าจอแบบ A, ฟอนต์ Urbanist + Anuphan ฝังในโปรแกรม (OFL) |

## กฎการอ่านไฟล์
- sheet ที่ชื่อมี "ใบกำกับ" = IV, "วางบิล" = BI, "ใบเสร็จ" = RE
- ค่าแต่ละช่องหาจากป้าย ("เลขที่", "วันที่ Date", "Due Date", "Payment Term", "PO", "รวมเงิน"/"ราคาไม่รวมภาษี", "ภาษีมูลค่าเพิ่ม", "รวมทั้งสิ้น"/"Net Total") แล้วอ่านค่าทางขวา หรือแถวถัดไป
- เลข B/R อ่านจากชื่อไฟล์ `NNCIV-xxxxxx-Bxxx-Rxxx`
- เดือนของบิล = เดือนของวันที่บนใบกำกับ
- วันครบกำหนด: ใช้ Payment Term (ถ้าไม่มีใช้ Due Date) · "เครดิต N วัน" = +N วัน · "เงินสด" = วันเดียวกัน · ถ้าเป็นวันที่ใช้วันที่นั้น
- ป้าย "ราคาไม่รวมภาษี" = ราคารวม VAT แล้ว → ก่อน VAT = รวม × 100/107
- บรรทัดที่ไม่มีจำนวน/ราคา (SN, สเปค) รวมเข้ากับรายการด้านบน
- เงินปัดเป็นสตางค์ (Decimal, ROUND_HALF_UP)

## กฎการตรวจ
ระดับ: `red` ผิด / `drop` ทิ้ง / `yellow` ข้อสังเกต / `blue` แจ้งให้ทราบ

| code | ระดับ | กฎ |
|---|---|---|
| BI_LINK | red | B ในชื่อไฟล์ ↔ sheet ใบวางบิล ↔ เลข NNCBI ต้องตรงกัน ไม่งั้นไม่นับเป็นวางบิล |
| RE_LINK | red | R ในชื่อไฟล์ ↔ sheet ใบเสร็จ ↔ เลข NNCRECEIPT ต้องตรงกัน |
| EXTRA_ITEM | red | ใบวางบิล/ใบเสร็จมีรายการที่ไม่มีในใบกำกับ |
| TAXID | red | เลขผู้เสียภาษีในใบวางบิล/ใบเสร็จไม่ตรงใบกำกับ |
| SUM_ITEMS | red | ผลรวมรายการ ≠ ยอดก่อน VAT (หรือ ≠ รวมทั้งสิ้น สำหรับบิลราคารวม VAT) |
| VAT_CALC | red | VAT ≠ 7% (±0.01) หรือ ก่อน VAT + VAT ≠ รวมทั้งสิ้น |
| DOC_AMOUNT | red | ยอดในใบวางบิล/ใบเสร็จ ≠ ใบกำกับ |
| REF_IV | red | เลขใบกำกับที่อ้างอิงในใบวางบิล/ใบเสร็จ ≠ เลขใบกำกับ |
| DUP_IV / DUP_BI / DUP_RE | drop | เลขซ้ำ → ใบที่วันที่บนบิลเก่าสุดชนะ · เลขเดิม+วันที่เดิม → ไฟล์ที่อัพโหลดทีหลังทับ |
| NAME | yellow | ชื่อลูกค้าในใบวางบิล/ใบเสร็จไม่ตรงใบกำกับ |
| TERM_CONFLICT | yellow | Due Date ขัดกับ Payment Term |
| MISSING_ITEM | yellow | ใบกำกับมีรายการที่ใบวางบิลไม่ได้เขียน |
| VAT_INCLUDED | blue | ราคารวม VAT แล้ว |
| PHONE | blue | เบอร์โทรหัวใบวางบิล/ใบเสร็จไม่ตรงใบกำกับ |

บิลที่มี `SUM_ITEMS` หรือ `VAT_CALC` ไม่นับยอดขาย · ใบวางบิลที่มี red ใด ๆ ของ BI ไม่นับเป็นวางบิล

## รายงาน
- หน้าภาพรวม: ก่อน VAT · ภาษีขาย · ใบวางบิล (จำนวนที่/ยอด) · ครบกำหนดเดือนถัดไปที่ยังไม่ได้รับ · ตารางบิล · ยอดตามลูกค้า · ผลตรวจ
- popup มุมขวาบน: ยอดวางบิลที่ยังไม่ได้รับเงิน แยกบริษัท พร้อมครบกำหนด / คาดว่าได้รับ / ปุ่ม "ได้รับเงินแล้ว"
- คาดว่าได้รับ = ครบกำหนด + ค่าเฉลี่ยวันที่ลูกค้ารายนั้นจ่ายช้า (จากประวัติรับเงิน)
- ส่งออก Excel: สรุปเดือน · รายการบิล · รายการสินค้า · ใบวางบิล & ครบกำหนด · ต้องตรวจ

## ข้อมูลและการอัพเดท
- ฐานข้อมูลแยกจากตัวโปรแกรม (`%LOCALAPPDATA%\InvoiceChecker\data.db`) · backup ก่อนอัพเดท/ย้าย schema เก็บ 10 ชุด
- ไฟล์ต้นฉบับอ่านอย่างเดียว · เก็บสำเนาไฟล์ที่นำเข้าไว้ใช้ทำรายงานปัญหา
- เปิดโปรแกรม → เช็ค GitHub Releases ล่าสุด → ปุ่ม "อัพเดท" โหลด .exe ใหม่ สลับไฟล์ เปิดใหม่
