# ตรวจบิล (Office-Check)

โปรแกรม Windows สำหรับตรวจไฟล์บิล .xlsx (ใบกำกับภาษี / ใบวางบิล / ใบเสร็จรับเงิน) ทำสรุปยอดรายเดือน และแจ้งเตือนยอดวางบิลที่ยังไม่ได้รับเงิน

สเปคเต็ม: [docs/spec.md](docs/spec.md)

## สำหรับนักบัญชี

1. ดาวน์โหลด `InvoiceChecker.exe` จากหน้า [Releases](https://github.com/bosskub121212/Office-Check/releases/latest) ครั้งแรกครั้งเดียว วางไว้ที่ไหนก็ได้ เช่นบน Desktop
2. เปิดครั้งแรก Windows อาจขึ้นหน้าจอ "Windows protected your PC" (เพราะโปรแกรมไม่ได้ซื้อใบรับรองลายเซ็นดิจิทัล) ให้กด **More info → Run anyway**
3. ลากไฟล์บิลของเดือนมาวางในหน้าต่าง (หรือกด **อัพโหลดบิล**) ตรวจผลทีละไฟล์ แล้วกด **บันทึก**
4. กดกระดิ่งมุมขวาบนเพื่อดูยอดวางบิลที่ยังไม่ได้รับเงิน ได้รับเงินแล้วให้กด **ได้รับเงินแล้ว** แล้วเลือกวันที่รับเงิน
5. มีเวอร์ชันใหม่ จะมีปุ่มสีม่วง "มีเวอร์ชันใหม่" ขึ้นมุมบน กดแล้วกด **อัพเดทตอนนี้** โปรแกรมจะปิดและเปิดใหม่เอง ข้อมูลไม่หาย
6. เจอปัญหา ไปที่ **ตั้งค่า → สร้างไฟล์รายงานปัญหา** แล้วส่งไฟล์ .zip ที่ได้ให้ผู้ดูแล

ข้อมูลเก็บที่ `%LOCALAPPDATA%\InvoiceChecker\` (ฐานข้อมูล, backups 10 ชุดล่าสุด, logs)

## สำหรับเครื่อง DEV

ต้องมี Python 3.12+ (ติ๊ก "Add Python to PATH" ตอนติดตั้ง)

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `run_dev.bat` | เปิดหน้าจอในเบราว์เซอร์ แก้ `ui/` แล้วกด F5 ดูผลได้ทันที |
| `run_app.bat` | เปิดเป็นหน้าต่างโปรแกรมจริง (pywebview) |
| `build_exe.bat` | ทดสอบ + build `dist\InvoiceChecker.exe` บนเครื่องตัวเอง |
| `release.bat 1.0.1` | ทดสอบ → push → สร้าง tag `v1.0.1` → GitHub Actions build และปล่อยเวอร์ชันให้เครื่องนักบัญชี |

ทั้งสอง run ใช้ข้อมูลในโฟลเดอร์ `dev-data\` แยกจากข้อมูลจริง

ทดสอบ: `python -m pytest -q`
- `tests/fixtures/` ไฟล์บิลปลอม สร้างจาก `python tests/make_fixtures.py`
- `tests/private/` ไฟล์บิลจริงของลูกค้า **ไม่ขึ้น git** (อยู่ใน .gitignore) วางไว้เฉพาะเครื่อง DEV

แก้บั๊กจากรายงานปัญหา: แตกไฟล์ zip ที่นักบัญชีส่งมา ใน `files/` คือไฟล์บิลที่มีปัญหา คัดลอกไปไว้ใน `tests/private/` แล้วเขียนเทสต์ให้เจอปัญหาเดียวกันก่อนแก้

## โครงสร้าง

```
app/
  reader.py     อ่าน .xlsx (หาค่าจากป้าย ไม่ยึดเลขแถว)
  checker.py    กฎตรวจภายในไฟล์
  ledger.py     กฎเลขซ้ำข้ามไฟล์ · สรุปเดือน · ครบกำหนด · คาดว่าได้รับ
  store.py      SQLite + backup
  export.py     ส่งออก Excel 5 sheet
  api.py        ฟังก์ชันที่หน้าจอเรียก
  updater.py    อัพเดทจาก GitHub Releases
  bugreport.py  ไฟล์รายงานปัญหา
ui/             หน้าจอ (แบบ A · Lavender Glass) ฟอนต์ Urbanist + Anuphan (SIL OFL)
```
